Angles Created by the Transverse Line

When a transverse line intersects two parallel lines, it creates 8 angles (4 at each intersection point). These angles have special relationships:

1. Corresponding Angles (Equal)

Angles in the same relative position at each intersection:

  • ∠1 = ∠5 (upper right)
  • ∠2 = ∠6 (upper left)
  • ∠3 = ∠7 (lower left)
  • ∠4 = ∠8 (lower right)

2. Alternate Interior Angles (Equal)

Angles on opposite sides of the transverse, between the parallel lines:

  • ∠3 = ∠6
  • ∠4 = ∠5

3. Alternate Exterior Angles (Equal)

Angles on opposite sides of the transverse, outside the parallel lines:

  • ∠1 = ∠8
  • ∠2 = ∠7

4. Co-Interior Angles (Supplementary - sum to 180°)

Also called consecutive interior or same-side interior angles:

  • ∠3 + ∠5 = 180°
  • ∠4 + ∠6 = 180°

5. Vertically Opposite Angles (Equal)

Angles opposite each other at the same intersection point:

  • ∠1 = ∠3 and ∠2 = ∠4 (at first intersection)
  • ∠5 = ∠7 and ∠6 = ∠8 (at second intersection)

6. Linear Pairs (Supplementary - sum to 180°)

Adjacent angles on a straight line:

  • ∠1 + ∠2 = 180°
  • ∠2 + ∠3 = 180°
  • ∠3 + ∠4 = 180°
  • ∠4 + ∠1 = 180°
  • (Similarly for ∠5, ∠6, ∠7, ∠8)

Key Properties

  • All acute angles are equal (if one angle is 60°, all acute angles are 60°)
  • All obtuse angles are equal (if one angle is 120°, all obtuse angles are 120°)
  • Each acute angle + each obtuse angle = 180°
  • These relationships only hold true when the lines are parallel
